# figures.json 规格

一个 JSON 文件描述整张海报的文字、箭头和小人。所有坐标都是**画布归一化坐标**（0–1），x 乘宽度、y 乘高度。

先跑一次 `--print-outline` 拿到主体的真实轮廓，再基于它写坐标——**不要靠肉眼估边缘**：

```bash
python3 scripts/compose.py --image photo.jpg --out /tmp/probe.jpg --print-outline
# {"canvas": [1536, 2048], "outline": {"top": 0.202, "bottom": 0.797,
#   "rows": [{"y": 0.0, "py": 0.2021, "left": 0.2806, "right": 0.2995, "width": 0.0189}, ...]}}
```

`rows` 每隔 5% 主体高度给一行：`py` 是画布归一化纵坐标，`left`/`right` 是主体在该高度的左右边界。

## 顶层结构

```json
{
  "text":  {"value": "先来一块", "x": 0.305, "y": 0.105, "size": 158},
  "arrow": {"from": [0.345, 0.215], "to": [0.398, 0.447], "curve": 22},
  "figures": [ ... ]
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `text.value` | string | 文案，2–5 个汉字；用户给定则逐字保留 |
| `text.x` / `text.y` | 0–1 | 文案中心点 |
| `text.size` | int | 字号（像素），默认画布高 ×0.077 |
| `arrow.from` | `[x, y]` | 箭头起点，一般在文案左下方 |
| `arrow.to` | `[x, y]` | 箭头尖端，落在主体上 |
| `arrow.curve` | number | 中段横向偏移（像素），给箭头一点弯度；长箭头要给到 30 以上才看得出来 |
| `arrow.width` | 5 | 笔宽（像素） |
| `arrow.head` | 34 | 箭头头部长度（像素） |

## 小人

```json
{
  "hip": [0.145, 0.792],
  "scale": 2.0,
  "lean": 2,
  "hands": [[0.126, 0.716], [0.166, 0.716]],
  "feet":  [[0.111, 0.832], [0.180, 0.834]],
  "prop":  {"type": "rib", "at": [0.701, 0.684], "w": 0.05, "h": 0.027, "rotate": -8}
}
```

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `hip` | 是 | 髋点（身体中点偏下），不是脚底，也不是头顶 |
| `scale` | 否 | 1.0 约 150px 高。主体表面的小人用 1.3–1.5，主体外的大一些用 1.8–2.1 |
| `lean` | 否 | 上半身横向倾斜，正数前倾，负数后仰 |
| `hands` | 否 | 两个手的落点，顺序为左、右。省则自然下垂（不给 `hands` 时不画抓握小爪） |
| `feet` | 否 | 两个脚的落点，顺序为左、右。省则自然站立 |
| `snap` | 否 | `"hands"` / `"feet"` / `["hands","feet"]` / `true`：把手（脚）自动吸附到主体真实轮廓上 |
| `snap_inset` | 否 | 吸附时往主体内侧缩多少（归一化），默认 `0.004`，负值往外探 |
| `prop` | 否 | 手上的小道具，目前支持 `rib`（一块小排骨轮廓） |

### 吸附：不再"悬空抓空气"

**别自己猜边缘。** 把手随手放在主体边缘附近（差 0.01–0.02 都没关系），加 `"snap": "hands"`，运行时会把每个手点投影到最近的轮廓边缘上：

```json
{"hip": [0.905, 0.565], "scale": 1.9, "lean": -2,
 "hands": [[0.885, 0.512], [0.885, 0.540]], "snap": "hands",
 "feet":  [[0.882, 0.620], [0.922, 0.622]]}
```

只要 `hands` 存在，手末端会自动画一个小爪（扣住边缘的那三根指头），所以"扶着"看起来是"抓住"。

也可以用轮廓锚点直接写手的位置，`y` 是主体相对高度（0=顶，1=底）：

```json
{"hip": [0.93, 0.60],
 "hands": [{"edge": "right", "y": 0.32, "inset": 0.004},
           {"edge": "right", "y": 0.42, "inset": 0.004}]}
```

### 比例常识（避免"蜘蛛腿"）

在 2048 高的画布上：

- 躯干 ≈ `26 × scale` px
- 头半径 ≈ `13.5 × scale` px
- 一条腿 ≈ `40 × scale` px，所以 `feet.y ≈ hip.y + 40×scale/2048`

手够到主体时，肩到手的距离不要超过 `1.5 × 19 × scale` px，否则手臂会被拉成两根细长杆。经验值：**`hip` 距离主体边缘约 0.03–0.04（归一化宽度）**，手放在边缘上或边缘外一点，其余交给 `snap`。距离不够就把 `hip` 往主体挪近，而不是硬拉手。

### 让动作成立的写法

| 想画的动作 | 怎么写 |
| --- | --- |
| 双手托举主体底边 | `hands` 两点的 y 等于主体底边 +0.005，x 分列 `hip.x` 两侧 0.02 |
| 坐在主体边缘 | `hip` 放在边缘内侧，`feet` 垂到边缘外下方 |
| 抱着细杆/花茎 | `hands` 两点都落在杆的 x 上，y 相差 0.03 |
| 踮脚够高处 | `hip` 靠近目标正下方，`hands` 指向目标，`feet` 并拢 |
| 推着主体走 | `lean` 取正负 2–4，`hands` 贴主体侧面，`feet` 一前一后 |
