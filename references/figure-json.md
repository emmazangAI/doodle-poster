# 小人怎么写（JSON 说明）

一个 JSON 文件，说清楚这张海报上的一句话、一条箭头、几个小人。

## 坐标怎么算

所有位置都是"相对整张图"的比例，不是像素：

- `0` 是左边（或上边）
- `1` 是右边（或下边）
- `0.5` 是正中间

先跑一次 `--print-bbox` 拿到主体范围，再照着写。比如它告诉你 `[0, 0.409, 1, 0.711]`，那就是说：主体从图的 40.9% 高处开始，到 71.1% 高处结束，横向铺满整张图。

## 整体长这样

```json
{
  "text":  {"value": "先来一块", "x": 0.305, "y": 0.105, "size": 158},
  "arrow": {"from": [0.345, 0.215], "to": [0.398, 0.447], "curve": 22},
  "figures": [ 这里放小人 ]
}
```

### 那句话

| 字段 | 写什么 |
| --- | --- |
| `value` | 2 到 5 个字。用户指定了就一字不改 |
| `x`、`y` | 这句话的中心放在哪 |
| `size` | 字多大。不写就按图高 ×0.077 自动算 |

### 那条箭头

| 字段 | 写什么 |
| --- | --- |
| `from` | 从哪开始，一般写在字的左下方 |
| `to` | 箭头尖指到哪，落在主体上 |
| `curve` | 弯多少。数字越大越弯，写 0 就是直线 |

## 一个小人长这样

```json
{
  "hip": [0.145, 0.792],
  "scale": 2.0,
  "lean": 2,
  "hands": [[0.126, 0.716], [0.166, 0.716]],
  "feet":  [[0.111, 0.832], [0.180, 0.834]],
  "prop":  {"type": "rib", "at": [0.701, 0.684], "w": 0.05, "h": 0.027, "rotate": -8}
}
```

| 字段 | 要不要写 | 意思 |
| --- | --- | --- |
| `hip` | 必写 | 屁股的位置。不是脚底，也不是头顶 |
| `scale` | 可不写 | 大小。1.0 大约 150 像素高。站在主体上的用 1.3 到 1.5，站在外面的用 1.8 到 2.1 |
| `lean` | 可不写 | 上身往哪斜。正数往前，负数往后 |
| `hands` | 可不写 | 两只手落在哪，先左后右。不写就自然垂着 |
| `feet` | 可不写 | 两只脚落在哪，先左后右。不写就自然站着 |
| `prop` | 可不写 | 手里拿的小东西，目前只有 `rib`（一块小排骨的轮廓） |

### 别把腿拉成蜘蛛腿

按 2048 高的图算：

- 身子：`26 × scale` 像素
- 脑袋半径：`13.5 × scale` 像素
- 一条腿：`40 × scale` 像素

所以脚的纵坐标，大概等于"屁股 + 0.04"。手去够东西的时候，肩膀到手的距离别超过 0.12，超了就把屁股往主体那边挪，别硬拉手。

### 常见动作怎么写

| 想让小人干嘛 | 怎么写 |
| --- | --- |
| 双手托着东西的底边 | 两个手的纵坐标写成"底边 + 0.005"，横坐标分在屁股两边各 0.02 |
| 坐在边沿上 | 屁股放在边沿内侧，脚垂到边沿外面的下方 |
| 抱着细杆、花茎 | 两只手都落在杆的横坐标上，纵坐标错开 0.03 |
| 踮脚够高处 | 屁股站在目标正下方，手往上指，两只脚并拢 |
| 推着东西走 | `lean` 写 2 到 4，手贴着侧面，两只脚一前一后 |
